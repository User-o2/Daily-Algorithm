## E LQ 聚合

> 贪心、数学

**全局最优解的结构特征**：
所有由`L`替换的`?`，一定在所有由`Q`替换的`?`的左侧！

**证明**：
设两个`?`的索引为 i 和 j 且 i < j 。若某个方案中，? 替换来的 Q 位于 索引 i，? 替换来的 L 位于索引 j。那么将此 i,j 索引的 Q,L 交换位置，可以证明 △LQ聚合增益 = -a+b+c-c-a+x = b+x >= 0
所以将替换 ? 为 L 放在 Q 之前一定可以得到更大的 LQ 聚合增益。

既然 L 一定位于 Q 左侧，那么将所有 ? 替换之后的结果一定是`L...LQ...Q`。所以只要找到 L 和 Q 的**替换分界线**即可。

代码中使用到了动态规划的思想，以至于单词遍历就可以实现最优解序列的求解：
```cpp
else //'?'
{
	cnt --;
	//cnt_L是变为Q带来的增益，cnt+cnt_Q是变为L带来的增益
	if(cnt_L > cnt+cnt_Q) //变为Q，直接结算
		res += cnt_L;
	else //变为L，蓄势待发
		cnt_L ++;
}
```
cnt_L 和 cnt+cnt_Q 是单调的，也就是 cnt_L 是单调不减的，cnt+cnt_Q是单调递减的，所以意味着`if-else`这俩分支的判断结果只会在分界线处跳变一次。

## F 应急布线
> 图论、贪心
设连通块的数量为cnt。
对于第一问“最少需要添加的应急跳线数量”，显然是cnt-1。
对于第二问“在接入跳线最少的前提下，单台计算机接入跳线数量最大值的最小可能值”，非常考验**数学贪心直觉**：
cnt个连通块，需要cnt-1条边，涉及`(cnt-1)*2`个端口（也就是度数）。要使得单台计算机接入跳线数量的最大者尽可能小，最优的布线策略是使得 n 个节点均摊这 cnt-1 条边即可：`((cnt-1)*2+n-1)/n`上取整。
> 若其中一个联通块的节点数大于1，那么就可以使其中每一个节点进行均摊度数，而不必仅仅通过一个度数进行连通。

## H 足球训练

> 数学、贪心、二分答案优化

核心在于**将乘积最大化问题转化为对数求和问题**（累乘取对数变为累加），并利用**贪心思想结合二分答案**来优化时间复杂度。

### 1. 数学模型转换：从乘积到对数求和

题目的原始目标是最大化队伍的整体实力，即所有队员最终实力值的乘积：
$$\max \prod_{i=1}^{n} (a_i + k_i b_i)$$

处理多个变量的大数乘积极易导致溢出，且不便于直接比较。引入自然对数 $\ln(x)$ 的严格单调递增性质，将“乘积最大化”等价转化为“对数求和最大化”：
$$\max \sum_{i=1}^{n} \ln(a_i + k_i b_i)$$
这一转换将原本的全局连乘问题，拆解解成了**每个队员独立贡献**的加法问题，为后续的贪心策略奠定了基础。

### 2. 贪心策略的推导：收益最大化

当面临 $m$ 天的训练资源时，我们需要决定每一天分配给谁。假设我们考察第 $i$ 名队员，如果给他增加 $1$ 天的训练（即 $k_i$ 变为 $k_i + 1$），队伍整体实力对数和的增加量（边际收益）为：
$$\Delta = \ln(a_i + (k_i + 1)b_i) - \ln(a_i + k_i b_i)$$

利用**对数的运算法则**，可以将其化简。那么对于某一个队员，增加对其一天的训练得到的增益为：
$$\Delta = \ln\left( \frac{a_i + k_i b_i + b_i}{a_i + k_i b_i} \right) = \ln\left( 1 + \frac{b_i}{a_i + k_i b_i} \right) = \ln\left( 1 + \frac{1}{\frac{a_i}{b_i} + k_i} \right)$$

由于 $\ln(1+x)$ 在 $x > 0$ 时是严格单调递增的，要使单次分配的边际收益 $\Delta$ 最大，就必须使 $\frac{1}{\frac{a_i}{b_i} + k_i}$ 最大，也就是**使分母 $\frac{a_i}{b_i} + k_i$ 最小**。

**贪心结论：** 也就是每次分配训练天数时，只需找到当前 $\frac{a_i}{b_i} + k_i$ 最小的队员，给他分配 $1$ 天即可！

> 如果可以推导出这个贪心结论，那么就可以使用**优先队列**模拟训练天数的分配，可以通过 60% 的测试数据。

### 3. 算法数学优化：二分查找寻找整数下界

如果直接使用优先队列（堆）模拟上述贪心过程，时间复杂度将是 $\mathcal{O}(m \log n)$。考虑到100%数据下 $m \le 10^9$，逐天模拟必然会超时（TLE），因此必须进行优化。

观察表达式 $\frac{a_i}{b_i} + k_i$，它可以拆分为整数部分和小数部分：
$$\frac{a_i}{b_i} + k_i = \left( \left\lfloor \frac{a_i}{b_i} \right\rfloor + k_i \right) + \frac{a_i \bmod b_i}{b_i}$$
因为每次分配 $k_i$ 增加 $1$，所以**小数部分永远保持不变**。起决定性作用的首先是整数部分 $\left\lfloor \frac{a_i}{b_i} \right\rfloor + k_i$。

我们可以利用**二分答案**来快速找到一个统一的整数阈值 $L$。

> 这里是一个**注水模型**，每次都会去寻找最小的 $\frac{a_i}{b_i} + k_i$ 进行训练，这样一天一天地进行训练，那么最终所有的 $\frac{a_i}{b_i} + k_i$ 会到达一个最小的水平面，这个水平面就是我们要寻找的 L。
> 类似水一定会优先填满最低洼的地方，以此类推，随着水的不断注入，所有的低洼处都会被逐渐拉平，形成一个统一的水平面。

- **二分目标**：寻找一个最大的整数 $L$，使得把所有队员的整数部分 $\left\lfloor \frac{a_i}{b_i} \right\rfloor + k_i$ 都至少提升到 $L$ 时，所需的总天数 `need` 不超过 $m$。
- **验证逻辑 (`check` 函数)**：遍历所有队员，如果某队员当前的整数部分 $\lfloor a_i/b_i \rfloor < L$，则需要给他分配 $L - \lfloor a_i/b_i \rfloor$ 天。累加所有需要的分配天数，判断是否 $\le m$。

### 4. 剩余天数的精确分配

通过二分找到最大的满足条件的阈值 $L$ 后，我们先批量执行分配：
对所有 $\lfloor a_i/b_i \rfloor < L$ 的队员，直接增加天数使其整数部分达到 $L$。

此时，消耗了 `need` 天，还剩余 $m - \text{need}$ 天。
对于这最后剩下的少量天数（必然满足 $m - \text{need} < n$），由于所有队员当前的整数部分至少为 $L$，我们只需要根据当前的精确值 $\left\lfloor \frac{a_i}{b_i} \right\rfloor + k_i$ 从小到大**排序**，将剩余天数依次分给最小的前 $m - \text{need}$ 个人、每人 $1$ 天即可。
